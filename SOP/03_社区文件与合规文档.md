## 1. `LICENSE` — 主代码许可
- Use a permissive license for max reuse: **MIT** is the classic default for tools/knowledge repos.
- **Signature:** keep the real author signature (e.g. `段雪健 (Duan Xuejian)`) — don't strip attribution. 保持真实作者署名，不要抹去。
- Add a lean footer note clarifying the repo holds **only original docs/code**, and OEM/third-party non-distributable content is out of scope of this license. 可在文末补充说明「仅含原创文档/代码；OEM/第三方不可再分发组件不在本许可范围」。
- Template: `templates/LICENSE.mt`.

---

## 2. `THIRDPARTY.md` — 第三方组件与并行许可清单
This is the compliance backbone. 这是合规核心。

| 组件 | 上游 | 许可证 | 用途 | 说明 |
|---|---|---|---|---|
| `ryzenadj` | [FlyGoat/RyzenAdj](https://github.com/FlyGoat/RyzenAdj) | **LGPL-3.0** | SMU access | dynamic-linked OSS |
| `WinRing0x64` | OpenLibSys | **Modified BSD** | kernel I/O | permissive |
| `inpoutx64.dll` | Logix4U | **Closed-source Freeware** | no-driver I/O fallback | **no redistribution right — do NOT ship the binary** |
| official console decompiled artifacts | OEM | **proprietary** | reverse study ref | **not published** |

- **Parallel coexistence:** these are separate licenses alongside the project's MIT, **not a derivative mix**. 并行共存，非派生混合体。
- **Do not ship binaries** of non-redistributable items; point people to upstream. 不可再分发组件**不要随仓带二进制**，指引用户去上游获取。
- Add a dated "license basis" section with source links (SPDX headers, Arch AUR metadata, vendor DLL metadata). 加上带日期的「许可依据」小节并附来源链接。
- Template: `templates/THIRDPARTY.mt`.

> **Lesson:** A **forced rewrite of public history may be needed** if binaries were accidentally committed — see [SOP/05](05_本地git初始化与安全提交.md) + filter-repo lesson.

## 3. `.github/SECURITY.md` — 安全政策
- Provide a **private channel** for reporting vulnerabilities (not public issues). 提供私有渠道报告漏洞。
- State supported versions, reporting scope, disclosure policy. 说明支持版本、报告范围、披露政策。
- Template: `templates/SECURITY.mt`.

---

## 4. `CONTRIBUTING.md` — 贡献指南（铁律）
- **Hard rules:** never commit private/reverse-engineering originals; no OEM binaries; no personal data.
- Redaction-first: placeholders + register in README About-Redaction.
- License boundary: don't mix GPL source into MIT tree; respect third-party licenses and update THIRDPARTY.
- Security reporting via SECURITY.md private channel.
- Contribution flow: fork branch → local scan → conventional commit → PR.
- Template: `templates/CONTRIBUTING.mt`.

---

## 5. `CHANGELOG.md` — 变更记录
- Use [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/) format, semver. 遵守 Keep a Changelog。
- Categories: `Added / Changed / Fixed / Security / Removed`. 分类。
- Note the release-preparation changes (redaction, compliance, tree re-org) in the unpublished/first-release section. 在首发/未发布段记录脱敏/合规/重组的变更。
- Template: `templates/CHANGELOG.mt`.

---

## 6. `.github/FUNDING.yml` — 赞助入口（可选）
- Keep it **all-commented by default** = no Sponsor button. 默认全注释 = 无 Sponsor 按钮。
- Uncomment channels you want (github / patreon / custom, e.g. 爱发电). When pushed, GitHub shows a Sponsor button on the repo page.
- If you use donation QR images in README instead, put them in `assets/` and reference them. 若改用 README 二维码，把这些图片放 `assets/`。
- Template: `templates/FUNDING.mt`.
